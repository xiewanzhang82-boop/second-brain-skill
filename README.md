# Second Brain Builder · 第二大脑构建器

> 一个 AI Skill：**回答几个问题，你的第二大脑就建好了。**
> 不用想文件夹怎么分，不用查教程，不用手动建 14 个目录。

---

## 这是什么

给 AI（Claude / WorkBuddy / 任何支持 Skill 的工具）用的一套指令 + 脚本。

**它解决一个问题**：每个人都知道该建个知识库，但 90% 的人卡在第一步——
> "我该建哪些文件夹？""这个笔记放哪？""建了之后怎么坚持？"

这个 skill 让 AI **逐步问你几个问题**，然后**一键生成整套骨架**，最后**教你它怎么转**。

├── 07_关系与合作/        # 人：联系人、合作方、师长

**每个分区里都有一份说明文件**，告诉你这里放什么、什么时候写、什么不该放。

## 核心不是文件夹

这是这套东西最想说的一句话：

> **文件夹只是骨架。真正让它活起来的，是「AI 主动问 → 你回 0/1 → 每晚沉淀」的闭环。**

### 三个机制

**① 每天开场**
AI 每天第一次对话先找你：日期 + 今天任务 + 几个要你拍板的问题。

**② 0/1 回报法**

任务顺序固定，你睡前只回一串数字：

```
1 0 1 1 0
```

`1` = 做了，`0` = 没做。AI 自动打勾，对没做的追问原因。

> 为什么这样设计？**习惯的敌人是摩擦。**
> 手动打勾要打开文件、点方框；回 0/1 只要打 5 个字符。
> 把反馈成本降到最低，是唯一能让系统活过两周的方法。

**③ 每晚沉淀**
你说一句「沉淀」，AI 把当天对话 + 你的日记 + 发的文件，合并成一篇复盘存进 `06_行动与复盘/`。

> 没有沉淀的记录 = 没发生。三个月后你不会记得今天想了什么。

## 怎么用

### 方式一：让 AI 自己跑（推荐）

把这个 skill 装进你的 AI 工具，然后说：

```
帮我搭个第二大脑
```

AI 会依次问你：
1. 怎么称呼你？
2. 你现在是什么状态？（学生 / 上班 / 自由职业）
3. 未来 1~3 年最想达成什么？
4. 东西现在主要散在哪？
5. 希望多久推你一次？

然后自动建好整套结构。

### 方式二：直接跑脚本

零依赖，只用 Python 标准库（3.8+）：

```bash
# 先预演，看看会建什么
python scripts/build_brain.py --path "D:/MyBrain" --name "张三" --dry-run

# 确认没问题就真建
python scripts/build_brain.py --path "D:/MyBrain" --name "张三"

# 只要几个分区（不要全套）
python scripts/build_brain.py --path "D:/MyBrain" \
  --sections "00_首页导航,01_个人档案,06_行动与复盘,99_临时收件箱"

# 跳过用不上的
python scripts/build_brain.py --path "D:/MyBrain" --skip "07_关系与合作,09_外部知识库"
```

**幂等设计**：已存在的文件不会被覆盖，重复跑安全。

## 设计原则

这几条是实际用下来最值钱的：

| 原则 | 为什么 |
|---|---|
| **编号前缀不是洁癖** | `00` 是入口，`99` 是回收站。数字让文件夹永远按重要性排序 |
| **收件箱只放 48 小时** | 超过就说明你不敢做决定。逼自己要么归档、要么扔 |
| **不要建空文件夹** | 用不上的分区直接跳过。空文件夹只产生愧疚感 |
| **日记便宜，复盘贵** | 前者自己写不耗精力，后者才需要 AI。混在一起两个都做不下去 |
| **靠推动，不靠意志力** | 系统能转起来是因为 AI 到点来问，不是因为你自律 |

## 常见问题

**Q：我用的不是 Obsidian，能用吗？**
能。骨架是普通 Markdown 文件 + 文件夹，任何笔记软件都能用。Obsidian 最合适是因为双链语法 `[[...]]`，但不是必须。

**Q：我不需要 14 个分区。**
那就砍。用 `--sections` 只留 3~4 个。**能用起来的简单系统，胜过完美的复杂系统。**

**Q：我真的会坚持吗？**
不承诺。只给你一个最小动作：**明天打开首页，填三行。** 坚持是从"每天 2 分钟"开始的。

**Q：会泄漏我的隐私吗？**
不会。脚本生成的是**空骨架**，不含任何真实个人数据。你的内容只在你自己的电脑上。

## 来源

这套结构不是设计出来的，是**用了半年磨出来的**。
每个分区的存在都有理由，每条规则背后都踩过坑——

现在抽出来，希望别人少走点弯路。
